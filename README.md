# AI Avatar Multimodal Analysis
This project builds a multimodal pipeline to analyze video data by combining audio, text, and motion features.

## Overview
The goal of this project is to understand how speech, tone, and body movements relate to meaning and engagement. The pipeline extracts and aligns multiple types of data from video:
* Speech content (transcription)
* Audio features (volume, pitch, energy)
* Body movement (pose landmarks)

## Pipeline
The project follows an end-to-end process:
1. Extract audio from video
2. Transcribe speech using Whisper
3. Analyze audio features (volume, pitch, energy)
4. Extract pose landmarks using MediaPipe
5. Align all data into time-based intervals
6. Generate structured output for further analysis

## Key Files
* `videoProcessor.py` → main pipeline combining all steps
* `audio transciptor.py` / `generateTranscript.py` → speech-to-text
* `audio_features.py` → energy, pitch, mood detection
* `decibel_calc.py` → volume and decibel changes
* `word_emphasis_analysis.py` → word-level sentiment and emphasis
* `MediaPipe_Test.py` → pose landmark extraction

## Methodology
* Whisper for speech recognition
* Librosa for audio feature extraction
* MediaPipe for pose detection
* Python (pandas, numpy) for data processing

Data is aggregated into time intervals (e.g., 5 seconds) to align text, audio, and motion features.

## Output
The pipeline generates:
* CSV / Excel files containing:
  * timestamps
  * transcript text
  * audio features (volume, pitch, energy)
  * word-level statistics
  * pose landmark data

## Applications
* AI avatar training
* Speech behavior analysis
* Emotion and engagement detection
* Human-computer interaction research

## Movement Generation
This section covers the machine learning pipeline that learns from the extracted pose data and generates new arm movement sequences.

### Requirements
Before running anything, make sure you have the following installed:
```bash
pip install torch numpy pandas scikit-learn joblib opencv-python mediapipe
```

You will also need to download the MediaPipe pose landmarker model file separately:
1. Go to https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker
2. Download the **Full** model
3. Save it somewhere on your computer, but write down the path

### Files
* `MediaPipe_Test.py` → extracts pose landmarks from a video and saves them to a CSV
* `model_train_generate/data_prep.py` → loads and prepares the landmark CSVs for training
* `model_train_generate/model.py` → defines the LSTM Autoencoder architecture (machine learning model)
* `model_train_generate/train.py` → trains the model and saves the best version
* `model_train_generate/generate.py` → generates new arm movement sequences
* `model_train_generate/visualize.py` → animates and saves the generated movement as a video

### Step 1 - Extract pose landmarks from your videos
Open `MediaPipe_Test.py` and update these three lines at the top to match the path of your files:
```python
video_path = "path/to/your/video.mp4"
model_path = "path/to/pose_landmarker_full.task"
csv_path   = "path/to/save/output.csv"
```
Then run:
```bash
python MediaPipe_Test.py
```
This will generate a CSV file with the joint coordinates for every frame of the video. Repeat for each video and save all CSVs into the `video_data/` folder.

### Step 2 - Train the model
Once all your CSVs are in `video_data/`, run:
```bash
python -m model_train_generate.train
```
This will automatically load and prepare all the data, train the model, and save the best version as `best_model.pth`. Training stops automatically when the model stops improving. This may take a few minutes depending on your computer.

### Step 3 - Generate new movement
```bash
python -m model_train_generate.generate
```
This will generate 5 new arm movement sequences and save them as CSV files in the `generated/` folder. You can change how many sequences are generated by editing this line in `generate.py`:
```python
generated = generate_movement(num_sequences = 5)  # change 5 to any number
```

### Step 4 - Visualize the generated movement
```bash
python -m model_train_generate.visualize
```
This will display an animation of each generated sequence and save the full video to `generated/generated_movement.mp4`.

```bash
# Note: once the model is trained you do not need to repeat Step 2

```

### Customization
**To change the body part being analyzed**, update this section in `data_prep.py`:
```python
# current --> right arm only
joint in col for joint in ['RIGHT_SHOULDER', 'RIGHT_ELBOW', 'RIGHT_WRIST',
                            'RIGHT_PINKY', 'RIGHT_INDEX', 'RIGHT_THUMB']

# full body example
joint in col for joint in ['SHOULDER', 'ELBOW', 'WRIST', 'HIP', 'KNEE', 'ANKLE']

```
Note: if you change body parts you will need to retrain the model.

**To generate longer movement sequences**, update this line in `generate.py`:
```python
for t in range(150):  # increase for longer sequences
```

**To re-train the model with new videos**, add the new CSVs to the `video_data/` folder and run Step 2 again.
